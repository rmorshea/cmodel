# Reference

The reference section is for looking up the public API, not for learning the package
from scratch.

Start here when you already know the task you are trying to complete and need exact
signatures or symbol-level details.

## Public modules

- [cmodel.base](base.md): `CModel` and `CFmt`
- [cmodel.types](types.md): built-in field aliases and counted format helpers

## What is not covered here

Internal implementation modules are intentionally left out of the generated reference.
They support the public API, but they are not the stable entry points most users should
build against.
